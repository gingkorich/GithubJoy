openvinotoolkit/openvino★ 11,598

OpenVINO 是一个面向工程师和模型部署人员的开源推理工具包，核心作用是把已经在 PyTorch、TensorFlow、ONNX、Keras 等框架中训练好的模型转换、优化并运行起来。用户可以安装 pip openvino，在 Python 或 C++ 代码中调用 convert_model 生成 OpenVINO 模型，再用 Core 选择 CPU、GPU 或 NPU 编译，最后向 compiled_model 传入数据并获得输出，适合计算机视觉、语音识别、大语言模型、文生图等推理场景。它的特别之处在于把训练框架和推理硬件解耦，让同一模型在边缘设备、PC、服务器或 Intel 加速硬件上部署，并且通过 NNCF、模型服务器、Hugging Face 集成等生态补充压缩、量化、服务化和生成式 AI 能力。

实现逻辑

Q1 · 用户从训练模型到推理调用的主入口是什么？

README 给出的 Python 主链是 import openvino as ov 后加载 PyTorch 或 TensorFlow 模型，再调用 ov.convert_model 转成 OpenVINO 模型。随后用 ov.Core().compile_model(ov_model, 'CPU') 绑定设备，得到 compiled_model，并以 compiled_model({0: example.numpy()}) 传入输入字典执行推理。C++ 和其他语言也遵循类似的模型转换、编译、推理调用方式，但示例材料主要展示 Python API。

Q2 · 跨框架模型支持的关键做法在材料里怎样体现？

README 说明 OpenVINO 能接收 PyTorch、TensorFlow、ONNX、Keras、PaddlePaddle、JAX/Flax 等框架模型，也允许通过 Optimum Intel 使用 Hugging Face 的 transformers 和 diffusers 模型。从用户接口看，差异主要被封装在 convert_model 前后，进入 OpenVINO 后再由 compile_model 选择 CPU、GPU 或 NPU。具体前端算子映射和转换 pass 未在给定源码文件中展开，只能基于 README/目录结构推断。
